B

df |>
  group_by(var_2)
# A tibble: 5 × 3
# Groups:   var_2 [2]
  var_1 var_2  var_3 
  <dbl> <chr>  <chr> 
1    10 Pizza  Apple 
2    20 Burger Apple 
3    30 Pizza  Pear  
4    40 Pizza  Pear  
5    50 Burger Banana

group_by function had no effect in this code chunk, but it groups the values based on the column passed as an argument. When we compare arrange with group_by function, arrange function sorts the rows based on the passed column and group_by groups rows that share the same value in the passed column.

C

df |>
  group_by(var_2) |>
  summarize(mean_var_1 = mean(var_1))
# A tibble: 2 × 2
  var_2  mean_var_1
  <chr>       <dbl>
1 Burger       35  
2 Pizza        26.7

This chunk groups the data based on the passed column var_2 that share the same value, then it creates two rows based on the mean_values of var_1 found within each new grouping in the “summarize” part.

D

df |>
  group_by(var_2, var_3) |>
  summarize(mean_var_1 = mean(var_1))
`summarise()` has grouped output by 'var_2'. You can override using the
`.groups` argument.
# A tibble: 4 × 3
# Groups:   var_2 [2]
  var_2  var_3  mean_var_1
  <chr>  <chr>       <dbl>
1 Burger Apple          20
2 Burger Banana         50
3 Pizza  Apple          10
4 Pizza  Pear           35

This chunk created groupings based on var_2 and var_3 in the group_by section. It created a new temporary column for the summarize section called mean_var_1 that has the mean values of rows of var_1. The message says that the summarize is based on var_2 and to change that you can use “.groups” argument.

E

df |>
  group_by(var_2, var_3) |>
  summarize(mean_var_1 = mean(var_1), .groups = "drop")

This chunk does pretty much the same thing as the last one with one exception, “.groups” ungroups the data after it summarizes
